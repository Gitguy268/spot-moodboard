# Security

Please don't open a public issue for a security problem. Use GitHub's [private vulnerability reporting](https://github.com/Gitguy268/spot-moodboard/security/advisories/new) instead.

The moodboard is a static page. It makes no requests besides its own files and Google Fonts, and it only stores the chosen look, filter and board positions in your browser's localStorage.

If a picture shows something that identifies a person or a place (a face, a readable name tag, an address), please report it the same way so it can be removed quickly.
